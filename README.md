# FitOS

Plataforma web para personal trainers gerenciarem alunos, exercícios, planos de treino, evolução e finanças.

## Governança

Este repositório é a fonte oficial do projeto. Entregas são organizadas na hierarquia:

`Roadmap → Sprint → Épico → História → Pull Request`

Commits, pushes e merges diretos na `main` são proibidos. Toda alteração, inclusive documentação, configuração e hotfix, deve chegar à `main` exclusivamente por Pull Request revisado e aprovado. Cada PR deve formalizar a entrega e estar associado a uma Sprint, um Épico e uma História documentada.
